# Loop the Playlist -- In-Class Activity

## Overview
In this activity, you will practice with for and while loops. You will trace short examples, predict what the code will print, and understand how loops repeat and stop.

## Prompt 1: For Loop
Look at the code and trace what happens each time the loop runs. Write down what you think will print before running the code.
- What will the program print?
- How many times will the loop run?
- What does "song" represent each time the loop runs?

## Prompt 2: While Loop
Trace the loop and keep track of how the variable changes each time it runs. Write down what you think will print before running the code.
- What numbers will be printed?
- How does "songs_left" change each time the loop runs?
- Why does the loop stop?

## What you're practicing
- Using a for loop to go through items in a list
- Understanding how a while loop repeats based on a condition
- Tracing code and predicting output
- Understanding how a variable changes and causes a loop to stop
