# Playlist Planner -- Functions Homework

## Overview
In this homework, you will create a program that organizes songs in a playlist. You will complete different tasks, including displaying song information and calculating playlist length. 

## Task 1: Song information
Write a function that takes a song's name and its length in minutes. Use the provided song information when calling the functions:
1. Just Dance; 4 minutes
2. Saturn; 3 minutes
3. From the Start; 3 minutes

## Task 2: Total Playlist Length
Write a function that takes the lengths of the songs and calculates the total length of the playlist. The function should return the total rather than print it.
